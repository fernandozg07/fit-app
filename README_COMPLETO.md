- `/workouts/:id` - Detalhes do treino

## 🚀 **COMO USAR**

### **Opção 1: Automático (Recomendado)**
```bash

```

### **Opção 2: Manual**
```bash
# Backend
python manage.py runserver

# Frontend (nova janela)
cd frontend
npm install
npm start
```
