### 🚀 **COMO USAR**

#### **1. Iniciar o App**
```bash
# Opção 1: Script automático
start-app.bat

# Opção 2: Manual
# Backend (terminal 1)
python manage.py runserver

# Frontend (terminal 2)
cd frontend
npm start
```

#### **2. Acessar o App**
- **Frontend:** http://localhost:3000
- **Backend:** https://web-production-567f4.up.railway.app
- **API Docs:** https://web-production-567f4.up.railway.app/swagger/

#### **3. Fluxo de Uso**
1. **Registre-se** com seus dados pessoais
2. **Faça login** com suas credenciais
3. **Explore o dashboard** com suas estatísticas
4. **Gere treinos** personalizados com IA
5. **Crie dietas** adaptadas aos seus objetivos
6. **Registre progresso** para acompanhar evolução
7. **Use o chat IA** para tirar dúvidas
